## 📺 NostalgiaVue — mobile & web release

**Watch now:** https://nostalgiavue.vercel.app

### Install on your phone
- **iPhone / iPad:** open the link in Safari › Share › **Add to Home Screen**
- **Android:** open the link in Chrome › ⋮ › **Install app**, or MENU › System › **📲 Add to Home Screen**

It runs full screen like a native app. Turn the phone sideways and hit **ZOOM** for screen-only mode, and swipe up or down on the screen to change channels.

### What's inside
- 760+ channels: NostalgiaVue Cable (31–200), YouTube (201–299), Podcasts (300–314), Docs · Gaming · Tech (315–350), More Cable (351–419), Bring-Your-Own (420+), Pay-Per-View (500–529), Maker Lab (530–549), Game Show Network (550–579), Late-night PPV (580–599), My Playlists (600s), LIVE (700s), Shows A–Z (800s), More Shows (900s)
- Local TV for 04240 (WCSH 6, WMTW 8, WCBB 10, WGME 13 …) and *Local on the 9s* weather
- Nine sets (three per decade) with matching remotes, real warm-up sounds and dial clicks
- Guide, Guide Channel, commercial breaks, generated station logos, power-on logo animation
- Local media (channels 1, 2, 4, 5, 7, 11, 14–20) and the Game Channel (3) over Tailscale
