# Remote & Controls

| Remote | Keyboard | What it does |
|---|---|---|
| ⏻ | `P` | Power. The tube warms up, the NostalgiaVue logo plays, then the last channel comes on |
| 0–9 | `0`–`9` | Punch in up to 3 digits (e.g. `1` `0` `9` for Stooge-O-Rama). It tunes after 1.5 s or the third digit |
| CH ▲▼ | `↑` `↓`, PgUp/PgDn | Channel up/down (hidden channels are skipped) |
| VOL ± | `←` `→`, `+` `-` | Volume |
| MUTE | `M` | Mute |
| LAST | `L` | Previous channel |
| GUIDE | `G` | Program guide. ▲▼ move, ◀▶ page, OK tunes |
| INFO | `I` | What's on, with a description and a link |
| MENU | `S` | Settings |
| BACK | `Esc` | Close overlays; quit a game back to the game list |
| ZOOM | `Z` | Screen only (hides the cabinet). Use MENU › Picture › *Go full screen* for full screen |
| PPV | | Jump to Pay-Per-View (500) |
| GAME | | Jump to the Game Channel (3) |
| ★ FIND | `F` | Add a channel |
| OK / ENT | `Enter` | Show the banner. On YouTube channels: ON DEMAND list. On local channels: your library with resume points. On LIVE channels: jump to the regular channel |
| SLEEP | `X` | Sleep timer: 15 › 30 › 60 › 90 › 120 min › off |
| CC | `C` | Captions (YouTube channels) |
| PIP | `N` | Picture-in-picture: your last channel in the corner |
| SWAP | `W` | Swap the PIP channel and the main one |
| FAV | `V` | Jump to the next favorite channel |
| FAV+ | `B` | Add/remove the current channel as a favorite (★ in the guide) |
| ● REC | `R` | Tape what's on to the VCR (channel 880) |
| VCR | | Go to the tape shelf (880); OK plays a tape, BACK ejects |

**Touch:** swipe up/down on the screen to change channels, and left/right for volume. In zoom mode, tap to bring up the control bar.

**The 80s sets:** the VHF dial really turns to channels 2–13, and you can click the knobs. On the console and the portable, **drag the rabbit ears** sideways: every channel comes in clearest at its own antenna angle.

**In the guide:** INFO flips between the four guide styles.

**TV remotes** (Android TV, Fire TV, smart-TV browsers): D-pad, OK, Back, CH±, Guide, Info, color buttons and CC all work.
