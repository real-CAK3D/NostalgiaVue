# Parental Controls

**MENU › Parental**

- **PIN:** set a 4-digit PIN. Nothing is locked until a PIN exists.
- **Locked categories:** *Half Baked* is locked by default. Tick any others: Horror, Comedy, Talk…
- **Locked channels:** by default 34 (Holy Moly), 273–274 (High Times, Grow Room), 289–290 (Jackass, Wildboyz), 419 (Half Baked) and 846 (Beavis and Butt-Head). Edit the list freely.
- **Kids profile:** shows only kids, cartoons, learning, nature, science, seasonal and cozy channels, plus weather, the guide and games. Everything else disappears from surfing and the guide. Turning it off needs the PIN.

A locked channel shows a 🔒 card. Type the PIN with the remote's number buttons; it stays unlocked until the TV is turned off. Changing any parental setting asks for the PIN.
